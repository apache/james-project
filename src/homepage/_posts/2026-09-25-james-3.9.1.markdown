The Apache James developers are pleased to announce James server 3.9.1 release.

Early adopters can [download it][download], any issue can be reported on our issue [tracker][tracker].

The Apache James PMC would like to thank all contributors who made this release possible!

## Security

This release addresses the following CVEs:

 - CVE-2025-66621 SASL OAUTHBEARER do not validate aud in JWT payload if misconfigred
 - CVE-2026-49939 Negative IMAP ACL administer authorization bypass through JMAP protocol
 - CVE-2026-74756 WebAdmin exposed without authentication on official Docker default
 - CVE-2026-76168 ManageSieve file implementation cross-user path traversal
 - CVE-2026-76171 SSRF filter bypass in the JMAP PushSubscription web-push client
 - CVE-2026-85111 Denial of service upon MIME parsing

Users are recommended to upgrade to 3.9.1 which addresses those issues.

## Announcement

This maintenance release brings numerous bug fixes, security enhancements and dependency upgrades to the 3.9.x line.

**Breaking change**: WebAdmin now generates a random password upon start up when none is configured, and logs it
(`password.generate`, defaults to `true`). WebAdmin is thus no longer unauthenticated out of the box, existing
deployments included. Please read the [upgrade instructions][upgrade] before upgrading.

Highlights of this release include:

- Several enhancements: Stricter Sieve script name and WebPush
target validation, OIDC SASL `aud` validation without introspection, as well as the upgrade of numerous dependencies
(Netty, ActiveMQ / Artemis, Log4J, Logback, BouncyCastle, Jackson, jsoup...).
- JMAP filtering rules gain a `moveTo` action, flag and date based criteria, and can be applied on existing mailboxes
through WebAdmin.
- JMAP: `Blob/copy`, negative ACLs, and `Email/set` updates combining move and flag changes.
- Customizable SMTP replies.
- Numerous stability fixes for the distributed server: mailbox and user rename, Cassandra inconsistencies solving,
task manager, IMAP pipelining and deleted message vault.
- The Glowroot agent is no longer bundled with James docker images.
