NOTE: Unlike the Guice applications, the {server-name} always starts its JMX server: there is no `jmx.enabled`
switch. When `conf/jmxremote.password` holds no credentials, as shipped, a random password is generated for
`james-admin` at start, in a file readable by its owner only; `conf/jmxremote.access` grants it `readwrite`. Both
files are read relatively to the `conf` folder.
